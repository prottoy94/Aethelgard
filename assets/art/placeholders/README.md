# Placeholder art

The game is **3D** (approved 2026-11-03, see 3D_PROPOSAL.md). World and character placeholders are now simple
3D shapes built inside the levels (see `src/world/test/test_level_3d.gd`); the old 2D sprite sheets were retired.

Only 2D **UI** placeholders remain, generated by `res://tools/placeholders/generate_placeholders.gd`:

| File | Size | Layout |
|---|---|---|
| `ui/element_icons.png` | 384×64 | 64×64 icons: Light (circle+rays), Wind (triangle), Frost (diamond), Earth (square), Fire (flame), Ember (cross). Shape and colour both differ (NFR-ACC-02). |
